# Search-and-Rescue-Fire-Fighting-Maritime-Drone
Its a project where I combined to MCU in one workflow and a bit of basic sensor based automation and I built it in 1 day and I just brought some parts newly but salvaged most of the parts from the Anti Submarine Warfare Maritime Drone.
Used one nodemcu for navigation and the servos workflow and connected a arduino nano with it vai voltage regulatory circuit and used it for automatic firefighting system and it's controlled over wifi.
